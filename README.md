# المدرّبة لارا · نسخة تجريبية

نسخة تجريبية من منصة الدورات «المدرّبة لارا»، تعمل في المتصفح بالكامل دون خادم.

- الدخول بأي بريد وكلمة مرور.
- التقدّم في الدروس يُحفظ في متصفحك فقط.
- الصور المرفوعة تبقى حتى إعادة تحميل الصفحة.

النسخة الكاملة مبنية بـ Python وSQLite، مع حسابات حقيقية وتتبّع للتقدّم على الخادم.
