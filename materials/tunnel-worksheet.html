نشر صفحة محلية عبر Cloudflare Tunnel

مرافقة لعرض «فهم الأنفاق في Cloudflare وآلية استخدامها عمليًا» · الزمن المقترح للجزء (أ): حوالي 25 دقيقة

قبل أن تبدأ

للجزء (أ): النفق السريع

  • جهاز Ubuntu متصل بالإنترنت
  • كلمة مرور جهازك (لأوامر sudo)
  • هاتف فيه بيانات جوال
  • لا تحتاج حساب Cloudflare ولا دومين

للجزء (ب): النفق المُدار

  • كل ما في الجزء (أ)
  • حساب Cloudflare
  • دومين مُضاف إلى Cloudflare

نافذتان

Terminal 1 للموقع
Terminal 2 للنفق
افتح أي نافذة بـ Ctrl+Alt+T

نعمل في مجلد تجريبي منفصل، وبصفحة تجريبية لا تحتوي أي بيانات شخصية. لا تضع في المجلد ملفات خاصة، لأن كل ما فيه سيصبح متاحًا عبر الرابط العام.

الجزء (أ): النفق السريع خطوة بخطوة

1

إنشاء مجلد التجربة والدخول إليه

Terminal 1
mkdir -p ~/tunnel-demo cd ~/tunnel-demo
وظيفته
ينشئ مجلدًا باسم tunnel-demo داخل مجلد المستخدم (الرمز ~)، ثم ندخل إليه.
المتوقع
لا تظهر أي رسالة؛ وهذا يعني النجاح.
تحقّق
نفّذ pwd، فيظهر مسار ينتهي بـ /tunnel-demo.
2

إنشاء صفحة HTML بسيطة

Terminal 1
cat > index.html <<'EOF' <!doctype html><meta charset="utf-8"> <h1 dir="rtl">مرحبًا! هذه الصفحة تعمل على جهازي</h1> EOF
وظيفته
يكتب ملفًا اسمه index.html فيه جملة ترحيب. الصفحة التي اسمها index تُعرض تلقائيًا.
المتوقع
لا تظهر رسالة.
تحقّق
نفّذ ls فيظهر index.html.
بديل أسهل
افتح محرر النصوص (Text Editor)، واكتب الأسطر الثلاثة الوسطى، واحفظها باسم index.html داخل المجلد tunnel-demo.
3

تشغيل خادم تطوير محلي

Terminal 1
python3 -m http.server 8000 --bind 127.0.0.1
وظيفته
يشغّل خادمًا صغيرًا مدمجًا في Python يعرض ملفات المجلد على المنفذ 8000، ويقبل الاتصال من هذا الجهاز فقط.
المتوقع
Serving HTTP on 127.0.0.1 port 8000 (http://127.0.0.1:8000/) ...
تحقّق
افتح المتصفح على http://localhost:8000 فتظهر جملة الترحيب.
اترك هذه النافذة مفتوحة. الأمر لا ينتهي ما دام الخادم يعمل؛ هذا طبيعي.
4

تثبيت cloudflared من مستودع Cloudflare الرسمي

Terminal 2 (نافذة جديدة)
# أ) مفتاح المستودع sudo mkdir -p --mode=0755 /usr/share/keyrings curl -fsSL https://pkg.cloudflare.com/cloudflare-main.gpg | sudo tee /usr/share/keyrings/cloudflare-main.gpg >/dev/null
# ب) إضافة المستودع echo 'deb [signed-by=/usr/share/keyrings/cloudflare-main.gpg] https://pkg.cloudflare.com/cloudflared any main' | sudo tee /etc/apt/sources.list.d/cloudflared.list
# ج) التثبيت sudo apt-get update && sudo apt-get install cloudflared
وظيفته
نضيف «متجر البرامج» الرسمي لـ Cloudflare ومفتاحه الذي يثبت أصالة البرامج، ثم نثبّت cloudflared منه.
المتوقع
يطلب كلمة مرور جهازك (لا تظهر أثناء الكتابة)، ثم قد يسأل Do you want to continue? [Y/n] فاكتب y ثم Enter.
تحقّق
cloudflared --version
يظهر سطر يبدأ بـ cloudflared version متبوعًا برقم الإصدار.
إن ظهر curl: command not found نفّذ أولًا: sudo apt-get install curl
5

تشغيل النفق السريع

Terminal 2
cloudflared tunnel --url http://localhost:8000
وظيفته
يفتح نفقًا مؤقتًا إلى Cloudflare، ويوجّه كل ما يصله إلى الخادم على المنفذ 8000.
المتوقع
سطور كثيرة، وبينها مربع فيه رابط ينتهي بـ trycloudflare.com (شكل تقريبي):
| Your quick Tunnel has been created! Visit it at ... | | https://random-words-here.trycloudflare.com |
تحقّق
افتح الرابط في متصفح اللابتوب أولًا، فتظهر الصفحة نفسها.
6

الاختبار من الهاتف

الهاتف
  • أطفئ الواي فاي في الهاتف، واستخدم بيانات الجوال.
  • أرسل الرابط إلى هاتفك (برسالة لنفسك مثلًا)، وافتحه.
المتوقع
تظهر جملة الترحيب على الهاتف: صفحتك وصلت من الإنترنت.
إن لم تظهر
انتظر بضع ثوانٍ وأعد المحاولة، وتأكد أن النافذتين ما زالتا تعملان.
7

تجارب الإيقاف (لفهم الاعتماديات)

التجربةكيف؟النتيجة المتوقعة على الهاتف
إيقاف الخادمCtrl+C في Terminal 1، ثم حدّث الصفحة على الهاتفصفحة خطأ من Cloudflare (غالبًا 502)
إعادة الخادمفي Terminal 1: السهم الأعلى ↑ ثم Enterالصفحة تعود بعد التحديث
إيقاف النفقCtrl+C في Terminal 2الرابط يتوقف نهائيًا
إعادة النفقفي Terminal 2: ↑ ثم Enterيظهر رابط جديد مختلف
8

إيقاف التجربة وتنظيف ما أنشأناه فقط

  1. اضغط Ctrl+C في Terminal 2 ثم في Terminal 1.
  2. تأكد من محتوى مجلد التجربة قبل حذفه:
    cd ~ ls ~/tunnel-demo
    المتوقع: index.html فقط.
  3. احذف مجلد التجربة وحده:
    rm -r ~/tunnel-demo
  4. اختياري: إن لم تعد تحتاج cloudflared:
    sudo apt-get remove cloudflared sudo rm /etc/apt/sources.list.d/cloudflared.list
انسخ أمر الحذف كما هو. لا تغيّر المسار، ولا تستخدم sudo مع حذف مجلد التجربة.

الجزء (ب): النفق المُدار برابط ثابت

يحتاج حساب Cloudflare ودومينًا مُضافًا إليها. نستخدم هنا demo.example.com مثالًا؛ ضع دومينك بدلًا منه. الخطوات من وثائق Cloudflare (مراجعة 2026-10-25)، وأسماء القوائم قد تتغير قليلًا مع تحديث اللوحة.
1

إنشاء النفق

لوحة Cloudflare
  1. Networking › Tunnels ثم Create a tunnel.
  2. اكتب اسمًا، مثل my-laptop، ثم Create Tunnel.
  3. اختر نظام التشغيل، وانسخ أمر التثبيت المعروض.
2

تثبيت cloudflared كخدمة على جهازك

Terminal

الأمر الذي تعرضه اللوحة يكون بهذا الشكل؛ انسخه كاملًا من اللوحة:

sudo cloudflared service install <TOKEN>
وظيفته
يحوّل cloudflared إلى خدمة نظام تعمل تلقائيًا، ومرتبطة بنفقك عبر الرمز (Token).
تحقّق
sudo systemctl status cloudflared
المتوقع: Active: active (running). اضغط q للخروج. وفي اللوحة تصبح حالة النفق Healthy.
الـ Token سرّ: لا تصوّره، ولا تشاركه، ولا تضعه في ملفات المشروع. إن تسرّب، استخدم Rotate token في صفحة النفق.
3

ربط الساب دومين بالخدمة المحلية

لوحة Cloudflare
  1. افتح النفق، ثم تبويب Routes › Add route › Published application.
  2. Subdomain: demo · Domain: اختر دومينك · Service URL: http://localhost:8000
  3. اضغط Add route. تنشئ Cloudflare سجل DNS من نوع CNAME يوجّه الاسم إلى النفق.
تحقّق
شغّل خادم الخطوة (أ-3)، ثم:
curl -I https://demo.example.com
المتوقع: سطر أول فيه 200، أو افتح الرابط من الهاتف.
4

إزالة النفق المُدار بعد التدريب (اختياري)

  1. من صفحة النفق احذف الـ Route، ثم احذف النفق.
  2. على الجهاز أزل الخدمة:
    sudo cloudflared service uninstall
